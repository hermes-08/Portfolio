COLLEGE OF CYBERSECURITY & DEFENSE


  1. Specialization Tracks
    1. Offensive Security (Red Teaming)
      • Penetration Testing: Simulating authorized cyberattacks to identify vulnerabilities in networks, web apps, and systems.
      • Exploit Development: Writing custom scripts and code to test system weaknesses before malicious actors exploit them.
      • Social Engineering: Testing human security awareness through simulated phishing, pretexting, and credential harvesting.
      • Web Application Hacking: Finding flaws like SQL injection, Cross-Site Scripting (XSS), and broken access controls.
      • Wireless Hacking: Intercepting traffic, breaking weak Wi-Fi encryption protocols, and detecting rogue access points.
    2. Defensive Security (Blue Teaming)
      • Security Operations (SOC): Monitoring real-time threat intelligence and analyzing system alerts for suspicious behavior.
      • Incident Response: Containing active cyber threats, eradicating malware, and restoring compromised systems safely.
      • Hardening: Configuring firewalls, applying patches, and restricting permissions to minimize the attack surface.
    3. Digital Forensics and Compliance
      • Memory Forensics: Analyzing volatile RAM dumps to recover hidden malware, passwords, and active network connections.
      • Log Analysis: Examining system, server, and firewall logs using SIEM tools to reconstruct attack timelines.
      • Chain of Custody: Preserving digital evidence properly so it remains admissible in legal and corporate proceedings.
      • Regulatory Compliance: Ensuring infrastructure aligns with frameworks like ISO 27001, NIST, GDPR, and PCI-DSS.
      • Risk Management: Assessing potential asset vulnerabilities, calculating risk metrics, and creating mitigation plans.


  2. Core Subjects
    1. Network Security and Fundamentals
      • OSI Model: Understanding packet movement across all seven layers from physical hardware to application protocols.
      • Wireshark: Capturing and inspecting live network packets to identify unencrypted traffic and suspicious payloads.
      • Firewalls & IDS/IPS: Deploying network defense rules to block unauthorized connections and detect anomalies.
      • Protocols: Analyzing TCP/IP, UDP, DNS, DHCP, and HTTP/HTTPS behavior under normal and attack conditions.
      • Virtual Private Networks: Encrypting remote connections using IPsec and TLS tunnels to safeguard data transmission.
      • Subnetting: Segmenting network spaces to restrict lateral movement during a security breach.
    2. Cryptography and Encryption
      • Public Key Infrastructure: Managing asymmetric key pairs, digital certificates, and trusted certificate authorities.
      • Hashing: Verification of file integrity using cryptographic algorithms like SHA-256 and MD5 without reversing functions.
    3. Ethical Hacking Methodologies
      • Reconnaissance: Gathering passive and active intelligence about target domains, employee emails, and tech stacks.
      • Scanning & Enumeration: Mapping open ports, active services, and OS versions using tools like Nmap.
      • Gaining Access: Exploiting verified vulnerabilities to establish initial footholds on target machines.
      • Privilege Escalation: Elevating user access privileges from standard accounts to administrative root rights.


  3. Required Lab Modules
    1. Setting Up the Attack Environment
      • Install Hypervisor: Download VirtualBox or VMware Workstation to run isolated virtual machines safely.
      • Deploy Attack OS: Set up Kali Linux or Parrot OS equipped with pre-installed penetration testing tools.
      • Configure Target Range: Spin up vulnerable lab VMs like Metasploitable or DVWA on an isolated internal network.
      • Establish Snapshots: Save clean state VM snapshots so you can reset systems instantly after breaking them.
      • Verify Isolation: Ensure target host machines cannot leak traffic to your home network or the public internet.
    2. Analyzing and Exploiting Vulnerabilities
      • Target Identification: Discover active IP addresses on the lab network using ARP scanning techniques.
      • Service Fingerprinting: Run detailed port scans to identify software versions running on open ports.
      • Search Exploits: Use databases like Exploit-DB to find matching proof-of-concept exploits for discovered versions.
      • Execute Payload: Launch an exploit through Metasploit to drop a interactive reverse shell on the victim machine.
      • Local Reconnaissance: Inspect system environment variables, local files, and running processes.
      • Identify Weakness: Spot misconfigured service permissions, unquoted service paths, or outdated kernel builds.
      • Escalate Rights: Execute privilege escalation vectors to capture system root privileges.
      • Document Findings: Record exact steps, evidence screenshots, and remediation recommendations for reporting.
    3. Defensive Hardening and Log Analysis
      • Endpoint Monitoring: Deploying Sysmon and Endpoint Detection tools to track process creation events.
      • Centralized SIEM: Routing host and network event logs to an Elastic Stack or Splunk dashboard for monitoring.
      • Create Detection Rules: Writing custom YARA or Sigma rules to trigger alerts when malicious scripts execute.
      • Block Malicious IPs: Updating firewall tables to drop connections from malicious command-and-control servers.
      • Revoke Compromised Credentials: Forcing password resets and invalidating active session tokens across active directory.
      • Patch Vulnerabilities: Applying missing security updates and closing unused network ports across all systems.


  4. Recommended Cybersecurity Books
    1. The Web Application Hacker's Handbook
      • Authentication Flaws: Identifying weaknesses in session management, cookie security, and multi-factor logins.
      • Injection Attacks: Crafting inputs to manipulate SQL queries, OS commands, and LDAP lookups.
      • Logic Flaws: Bypassing application workflows by manipulating parameters and request sequences.
      • Client-Side Threats: Understanding DOM-based vulnerabilities, clickjacking, and CORS misconfigurations.
    2. Practical Malware Analysis
      • Static Analysis: Inspecting executable binaries, imported functions, and hardcoded strings without running them.
      • Dynamic Analysis: Running suspicious files inside isolated sandboxes to observe file system and registry changes.
    3. Applied Network Security Monitoring
      • Threat Hunting: Proactively searching through network telemetry to uncover persistent undetected adversaries.
      • Packet Crafting: Building custom network packets using Scapy to test network filter controls.
      • Snort & Suricata: Writing signature-based detection rules for open-source Intrusion Detection Systems.
      • Traffic Baselining: Establishing standard network behavior profiles to spot anomalies rapidly.
      • DNS Telemetry: Tracking DNS requests to identify malware beaconing and domain generation algorithms.
      • Decryption Inspection: Setting up inline SSL/TLS inspection to analyze encrypted attack vectors.


  5. Grading Criteria Breakdown
    1. Final Practical Exam (Capture The Flag)
      • Significant Weight: Practical CTFs carry heavy weight—typically accounting for 30% to 50% of your final grade.
      • Essay: Comprehensive threat model assessments requiring written strategic defensive evaluations.
      • Project-Based: Live penetration test evaluations, hands-on red team labs, or technical portfolio reports.
      • Cumulative Scope: Tests all skills covered—from network scanning and initial access to root escalation and reporting.
    2. Midterm Penetration Testing Report
      • Practical Application: Instead of memorizing terms, you conduct an audit on a vulnerable network and report findings.
      • Rubric-Driven: Graded on vulnerability accuracy, executive summary clarity, technical depth, and remediation advice.
      • Literature: Research papers analyzing emerging threat actors, APT strategies, and attack frameworks.
      • Arts: Designing network topology security diagrams, threat landscape infographics, and posture roadmaps.
    3. Lab Quizzes and Assignments
      • Purpose: They ensure you complete hands-on lab challenges weekly to prevent cramming before final CTF events.
      • Scope: Covers 1–2 recent security concepts or practical command-line tool usage exercises.
      • Pop Quizzes: Unannounced syntax or protocol checks to ensure you know core tools like Nmap and Metasploit.
      • Concept Checks: Quick 2–3 question evaluations at the start or end of a lab session.
      • Lab Reports: Reinforce concepts through hands-on practice—like analyzing packet captures or writing exploit code.
      • Weight: Ranges from quick port-scanning assignments to complex malware analysis challenges, making up 10% to 25% of your grade.
      • Self-Assessment: Working independently in attack ranges highlights technical skill gaps before high-stakes CTF exams.
    4. Class Participation
      • Quality Over Quantity: Active participation means offering threat insights, helping peers debug scripts, or suggesting attack vectors.
      • Continuous Assessment: Evaluated continuously throughout the term during live attack-and-defense team exercises.
      • Group Work: Collaborating effectively during blue team defense simulations and group incident response drills.
      • Verbal Discussion: Explaining vulnerability impact clearly during threat modeling discussions and debriefs.
